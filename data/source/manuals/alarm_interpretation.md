# Confirm the record

Record the displayed message, equipment identifier, operating state, and time. Compare the message with the approved document version for that equipment. Do not infer a code meaning from a different model or an unverified note.

# Review related evidence

Check the event history and the service handover record for related observations. A cleared message that returns is still evidence and should remain attached to the case.

# Escalate uncertainty

If the approved source does not define the message, or multiple warnings make the state unclear, stop the scripted diagnosis and escalate to a qualified reviewer. Never bypass an interlock to clear an alarm.
