# Image capture

Only capture inspection images when the site procedure permits it. Frame the complete component, include an undamaged reference when available, and avoid opening or touching energized equipment for a photograph.

# Visual observations

Record visible cuts, abrasion, discoloration, unexpected bends, loose routing, or layout differences as observations rather than diagnoses. Preserve the original image and link any derived heatmap to it.

# Safe disposition

A model score cannot declare electrical equipment safe. Visible damage, overheating, uncertain isolation, or disagreement between the image and approved layout requires qualified human review before return to service.
